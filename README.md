# 💻 Student Grade Calculator

A responsive web application built with HTML, CSS, and JavaScript to calculate students' total marks, percentage, and final grades.

## 🌐 Live Demo

Open the live calculator: https://muhammadhamza560.github.io/student-grade-calculator/

## ✨ Features

- Five subjects available by default
- Option to add more subjects
- Automatic total marks calculation
- Automatic percentage calculation
- A+ to F grading system
- Input validation for marks between 0 and 100
- Reset functionality
- Responsive dark-themed interface

## 🎯 Grading System

| Percentage | Grade |
|---|---|
| 90–100% | A+ |
| 80–<90% | A |
| 70–<80% | B |
| 60–<70% | C |
| 50–<60% | D |
| Below 50% | F |

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript

## 🚀 Run Locally

1. Clone or download this repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
4. Start entering marks and calculate your results.

## 📚 Learning Objectives

This project demonstrates requirements implementation, DOM manipulation, input validation, mathematical calculations, responsive UI design, and deployment using GitHub Pages.
